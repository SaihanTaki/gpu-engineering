## Where the course stands

This is an early release. Part 0 and chapters 1 and 2 are written; the rest of
the course follows the outline in `plan.md` in the repository, one part at a time:

| Part | Covers |
|---|---|
| 0. Why GPUs? | Throughput versus latency, and the toolchain from Python down to machine code |
| 1. Foundations | Architecture, the programming model, a first kernel, warps, occupancy |
| 2. Memory hierarchy | Coalescing, shared memory, bank conflicts, caches, a transpose case study |
| 3. Parallel patterns | Reduction, scan, histograms, stencils, sorting, sparse matrices |
| 4. Performance engineering | The roofline model, matrix multiply step by step, streams, profiling |
| 5. AI kernels | Tensor cores and mixed precision, softmax and LayerNorm, FlashAttention |

The course is free and open source. Code is MIT licensed and course text is
CC BY-SA 4.0. Corrections and new chapters are welcome through GitHub.
